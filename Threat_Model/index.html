Key Components & Roles

App / Chat UI

User entry point; sends prompts over HTTPS to the orchestrator; streams answers back.

API Orchestrator

FastAPI (example). AuthN/AuthZ, rate-limits, audit logs. Calls Retriever + LLM.

IR Retriever

Embeddings + keyword search. Pulls relevant chunks from the knowledge index.

Vector / Cache

Stores embeddings and “hot” results for low-latency answers.

LLM

Receives Prompt + Retrieved Knowledge; streams grounded answers.

Observability

Metrics, traces, logs; security alerts for model abuse & data exfiltration.

Data Flows (Simplified)

[User/Chat] --HTTPS--> [API Orchestrator]
       ├─ validate/authz/audit
       ├─→ query --> [IR Retriever] --top-k--> [Vector/Index]
       └─ combine (prompt + knowledge) --HTTPS/stream--> [LLM]
                                   └─ result --→ Orchestrator --→ User

All links are TLS-encrypted; identities verified; I/O scanned for policy violations.
